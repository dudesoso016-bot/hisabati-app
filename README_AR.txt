حساباتي — حزمة PWA للأندرويد
1. ارفع محتويات هذه الحزمة إلى جذر مستودع GitHub Pages.
2. تأكد من وجود index.html وmanifest.json وsw.js ومجلد icons مع الصورتين.
3. في Settings > Pages اختر Deploy from a branch ثم main و/(root).
4. افتح رابط GitHub Pages في Chrome على Android ثم اختر تثبيت التطبيق إن ظهر الخيار.
الخصوصية: السجلات محفوظة في localStorage داخل المتصفح ولا تتم مزامنتها تلقائياً. احتفظ بنسخة احتياطية آمنة. لا ترفع ملف backup JSON إلى مستودع عام.
